# TNoti

교내 맞춤형 공지 알림 서비스. 한국공학대학교 전체공지에서 관심 카테고리와 키워드에 맞는 새 공지를 찾아 알려준다. 시스템분석설계 과목 프로젝트다.

## 지금 들어 있는 것

수집기만 있다. 화면, 로그인, 알림 발송은 아직 없다.

- `collector/` 공지 수집기 (Node.js)
- `data/notices.json` 수집한 공지
- `data/collect_log.json` 수집 기록. 바뀐 게 있거나 실패했을 때만 남긴다
- `.github/workflows/collect.yml` 10분마다 수집기를 돌리는 설정
- `supabase/migrations/` DB 테이블을 만드는 스크립트. Supabase 프로젝트에 이미 적용돼 있다

## 수집기가 하는 일

1. 전체공지 목록의 첫 페이지(최신 10건)를 한 번 읽는다.
2. 새 공지를 저장하고, 제목과 작성 부서로 카테고리를 붙인다.
3. 제목에 `~11. 20.` 같은 기한 표현이 있으면 마감일로 저장한다.
4. 첫 페이지에 남아 있는 공지의 제목이 바뀌거나 공지가 지워지면 반영한다.
5. 수집 결과를 Supabase DB에 반영한다. 서버용 키는 저장소 비밀 값 `SUPABASE_TNOTI_KEY`에서 읽는다.

## 수집 범위

학교 `robots.txt`는 `/bbs/` 경로의 자동 수집을 금지한다. 게시글 본문, RSS, 목록 2페이지 이후가 모두 이 경로에 있다. 그래서 수집기는 허용된 목록 페이지 한 곳(`/tukorea/7607/subview.do`)만 10분에 한 번 요청하고, 본문은 가져오지 않는다. 목록의 제목은 50자까지만 제공되므로 긴 제목은 잘린 채 저장된다.

## 직접 돌려 보기

```bash
cd collector
npm ci
npm test                 # 학교 사이트에 요청하지 않는다
node collect.mjs         # 목록 페이지를 한 번 요청한다
```

분류 규칙은 `collector/rules.json`에 있다. 잘못 분류된 공지가 보이면 이 파일의 키워드를 고친다.
